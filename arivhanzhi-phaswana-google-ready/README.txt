ARIVHANZHI PHASWANA — GOOGLE-READY PORTFOLIO

This package is prepared for GitHub Pages and search-engine indexing.

Files:
- index.html — portfolio homepage with SEO metadata and structured data
- profile.jpg — profile photo
- robots.txt — allows search engines to crawl the site and points to the sitemap
- sitemap.xml — search-engine sitemap
- manifest.json — web app metadata
- favicon.svg — browser/search branding icon
- 404.html — friendly missing-page fallback

Published URL configured in this package:
https://arivhanzhiphaswana1-art.github.io/

IMPORTANT:
Google indexing is not automatic or instant. After publishing:
1. Open Google Search Console.
2. Add the exact website URL above as a URL-prefix property.
3. Verify ownership using one of Google's available methods.
4. Submit: https://arivhanzhiphaswana1-art.github.io/sitemap.xml
5. Use URL Inspection for the homepage and request indexing.

Custom domain:
A professional domain can be connected later. Buying a domain requires the account/payment of the domain owner and cannot be completed from this ZIP alone.
